# RESCENE TOP5 PICK — 공개 웹사이트 프로젝트

## 로컬 실행
Node.js 20.9 이상이 필요합니다.

```bash
npm install
npm run dev
```

`http://localhost:3000`에서 게임을 실행합니다.

## Vercel 공개 배포
1. 이 프로젝트 폴더 전체를 GitHub 저장소에 업로드합니다.
2. Vercel에서 GitHub 저장소를 Import합니다.
3. Framework Preset을 Next.js로 확인하고 Deploy합니다.
4. 생성된 공개 주소에서 게임을 테스트합니다.

## 결과 공유
- 호스팅된 환경에서는 `/r/{결과데이터}` 형식의 고유 URL을 생성합니다.
- 별도 데이터베이스 없이 URL 자체에 TOP5 결과를 담습니다.
- 결과 페이지는 URL별 제목·설명 및 동적 Open Graph 미리보기 이미지를 제공합니다.
- `file://` 로컬 실행에서는 기존 hash 공유 방식이 유지됩니다.

## 게임 규칙
1. 1R: 5곡 중 3곡, 6그룹 (30 → 18)
2. 2R: 3곡 중 2곡, 6그룹 (18 → 12)
3. 3R: 3곡씩 4그룹. 앞 3개 그룹에서 2곡, 마지막 그룹에서 1곡 선택 (12 → 7)
4. FINAL: 7곡 풀 리그전 21경기, 승리 1점
5. 2곡 동점은 승자승, 3곡 이상 동점은 사용자 직접 순위 지정
6. 승점 상위 5곡이 최종 TOP5

## 참고
- 비공식 팬 프로젝트이며 RESCENE 및 앨범 이미지 관련 권리는 각 권리자에게 있습니다.
- 앨범 커버는 외부 HTTPS 이미지 주소를 참조합니다. 공개 운영 전 이미지의 이용 조건과 외부 표시 안정성을 확인해야 합니다.
- 공유 URL을 가진 사람은 결과를 볼 수 있습니다. 계정 또는 개인정보는 수집하지 않습니다.
